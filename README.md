# Credit Risk & Loan Default Analysis

## 1. Project Overview

This project focuses on analysing customer credit risk and identifying the factors associated with loan defaults.

The objective is to explore borrower characteristics, understand default patterns, and generate meaningful insights that can help financial institutions improve credit risk assessment and lending decisions.

The project follows an end-to-end data analytics workflow, starting with data cleaning and exploratory analysis and progressing to SQL-based analysis and interactive Power BI dashboards.

## 2. Business Problem

Financial institutions face challenges in assessing borrower creditworthiness and identifying customers who are more likely to default on their loans.

Understanding the relationship between customer demographics, income, loan characteristics, and previous credit history can help financial institutions make more informed lending decisions.

This project investigates these factors to identify patterns associated with loan defaults.

## 3. Business Questions

The analysis focuses on answering the following questions:

- What is the overall loan default rate?
- Which customer age groups have higher default rates?
- How does customer income influence loan defaults?
- Which loan grades are associated with higher default rates?
- Does loan purpose influence default behaviour?
- How does previous credit default history relate to loan defaults?
- Does home ownership have any relationship with default patterns?
- Which customer segments demonstrate higher credit risk?

## 8. Key Insights

The analysis aims to identify:

- Customer segments associated with higher loan default rates.
- Relationships between borrower income and default behaviour.
- Loan grades and purposes associated with increased credit risk.
- The influence of previous credit default history.
- Customer characteristics that may require additional credit risk assessment.

## 9. Business Recommendations

Based on the analytical findings, financial institutions can consider:

- Strengthening credit assessments for higher-risk customer segments.
- Reviewing lending policies for loan categories with elevated default rates.
- Incorporating previous credit history into borrower risk evaluations.
- Monitoring customer segments with higher default rates.
- Using data-driven insights to support lending and risk management decisions.
